Yes — because the backend and frontend are in **two different repos**, the best approach is to use **two-stage prompts**:

1. **Backend Discovery Prompt**
   Ask the agent to extract the Calendar Agent API contract, endpoints, request/response payloads, auth details, and expected UI behavior from the backend repo.

2. **Frontend Integration Prompt**
   Feed that backend contract into the frontend repo prompt and ask the agent to integrate it into the existing React chat UI using the current frontend architecture.

This is better than directly asking the frontend agent to “guess” the backend behavior.
